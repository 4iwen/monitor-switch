# Monitor Switch 0.4.0

本次更新面向 macOS 和 Windows，加入全局快捷键和“切回上一个输入源”，并修复输入源状态与设置保存问题。

## 新功能

- 为每台显示器的各个输入源分别设置全局快捷键，默认不占用任何组合键。
- 在设置页顶部配置“切回上一个输入源”快捷键，也可以从状态栏菜单直接执行。
- 快捷键支持录制、清除、重复检查和系统注册冲突提示；录制期间暂停已有快捷键。
- 每台显示器独立记录本次运行中的切换历史。执行切回前重新读取当前输入源，读取失败时不猜测目标。

## 修复与体验优化

- 旧的异步读取结果不再覆盖较新的切换或设置。
- 短暂读取失败时保留上次已知输入源并标记待确认。
- 原生菜单保持同一个实例，减少刷新时的位置与视觉跳动。
- 隐藏接口设置可正确保存；新接口配置继承已有 DDC 后端。
- 设置刷新保留草稿，关闭时提示未保存修改，保存失败时提供页内反馈。

## 下载与使用

- **Windows**：下载 `Monitor-Switch-Windows.zip`，解压后运行 `Monitor Switch.exe`。
- **macOS**：下载 `Monitor-Switch-macOS.zip`，解压后将 `Monitor Switch.app` 放入 Applications。
- 已有输入源配置保持兼容；快捷键需要在设置中自行指定。
- 0.3.0 仅为本地开发版本，本次统一以 0.4.0 发布。

## 验证范围

本地通过 Rust 测试、Clippy、设置页交互/布局检查，以及 macOS 原生快捷键注册、冲突与释放检查。Windows 包由 GitHub Actions 构建；Windows 实机快捷键和显示器往返切换仍需使用者验证。macOS 包采用临时签名，尚未进行 Apple 公证。

切换历史在退出后重置。DDC 命令被接受不等于显示器已完成物理切换；实际能力取决于显示器、显卡和连接路径。
