# Monitor Switch 0.4.1

本次为 macOS 和 Windows 的可靠性修复版本，已有输入源名称和快捷键配置保持兼容。

## 修复

- 修复首次使用缺少配置文件时无法切换的问题，无需先保存设置或配置快捷键（#1）。
- 菜单结构更新延后至菜单关闭，避免选择过程中刷新导致跳动。
- 增加单实例保护：再次打开程序会唤起已有实例的设置窗口，避免重复图标和快捷键冲突。
- 显示器连接变化、系统唤醒后自动重新发现显示器，合并重复事件并串行扫描，无后台轮询。
- 配置使用临时文件同步写入后原子替换，读取错误会在设置页显示，避免出现配置悄悄恢复默认的假象。
- Windows 原子替换遇到短暂文件占用时有限重试，保留原配置。
- 恢复快捷键时逐个注册，一个冲突组合不会停用其他可用快捷键；录制框失焦或设置关闭时恢复快捷键。
- 保存设置或切换打断扫描时重新排队，防止旧扫描结果覆盖新设置。

## 调整

- 移除输入源菜单的当前状态打勾，以及“当前输入源未知/待确认”文案。
- 打开菜单和切换后不再为了更新当前状态而读取输入源。“切回”保留独立历史，并在执行时重新读取。

## 下载

- **Windows**：下载 `Monitor-Switch-Windows.zip`，解压后运行 `Monitor Switch.exe`。
- **macOS**：下载 `Monitor-Switch-macOS.zip`，解压后将 `Monitor Switch.app` 放入 Applications。

## 验证范围

本地通过 40 项 Rust 测试、macOS 与 Windows 目标 Clippy、设置页交互检查，以及 macOS 原生通知和重复启动检查。Windows 目标通过交叉编译检查；实机热插拔、窗口唤起和显示器往返切换仍待验证。

macOS 包采用临时签名，尚未进行 Apple 公证。“切回”历史在退出后重置。
